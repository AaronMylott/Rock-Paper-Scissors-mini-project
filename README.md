# Rock Paper Scissors

A simple command-line Rock, Paper, Scissors game built in Python.

## Features

- Play against a computer opponent
- Random computer choices
- Win, lose, and tie detection
- Replay functionality
- Uses functions to organise game logic

## Technologies

- Python 3
- Random module

## Purpose

This project was created to practise Python fundamentals, including functions, loops, conditional statements, user input, and return values.
